1) 팀 소개

팀원: 황정아, 이시훈, 이준수
수행 목표: 멀티 모달 기반 분류 시스템 구현 및 단일 모달 대비 성능 비교 분석
2) 프로젝트 주제 및 동기

주제: 포켓몬 도감 자동 인식 시스템
입력: 이미지 (카메라 촬영 / 출력물), 음성 (포켓몬 울음소리, 노이즈 포함)
출력: 포켓몬 클래스 분류
핵심 비교: Image only vs Image + Audio
동기: 멀티 모달 학습의 성능 향상 검증, 실제 환경 반영 (회전, 노이즈)
3) 필요 요소 (계획 및 기술)

데이터
이미지: 포켓몬 이미지 (다양한 각도), 증강: 회전, blur, 밝기 변화
음성: 울음소리 데이터, 노이즈 추가 (환경 소음)
모델
이미지 모델: CNN (ResNet 등)
음성 모델: Spectrogram 변환 → CNN
멀티 모달: Feature concatenation 기반 fusion
실험
Image only
Audio only
Image + Audio
평가
Accuracy
F1-score
성능 비교 및 케이스 분석
4) 역할

황정아: 데이터 수집, 이미지/음성 전처리, 데이터 셋 구성 및 관리
이시훈: 이미지 모델 구현, 음성 모델 구현 멀티 모달 모델 설계 및 학습
이준수: 실험 설계, 성능 평가 및 분석, 결과 정리 및 시스템 통합
5) 스케줄

1주차: 주제 확정, 역할 분담
2주차:  데이터 수집 및 전처리
3주차: 단일 모달 모델 구현
4주차: 멀티 모달 모델 구현 및 학습
5주차: 성능 비교 및 분석
6주차: 보고서 작성 및 발표 준비
